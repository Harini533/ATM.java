FEASIBILITY AND VIABILITY

⟶ Feasibility Analysis:

  • Technical: Built entirely on proven, open-source
    technology — nothing experimental.

Operational: Plugs into existing
government systems (ULPIN,
NGDRS, Bhoomi) instead of
replacing them.

  • Financial: Uses free/open tools and public
    data, so cost stays low.

  • Time: MVP deliverable quickly; advanced
    features added in phases.

⟶ Viability :

  • Main risk: Inconsistent land data across states

  • Mitigation: Federated design that queries existing state systems
    rather than forcing one central database.

  • Privacy risk: Sensitive landowner data.

  • Sustainability: Rides on an already-funded government
    mandate, so it doesn't need fresh budget to survive.

Canvas
The main navigation contains buttons for document level options. To switch between buttons, use the left and right keys and to activate, press Enter. To skip to the canvas, press “Ctrl+F2”.
The canvas is where your design is. To navigate into the page, press Enter. To navigate into groups or elements on the page, press Enter again. Press tab to move to the next page, group, or element. To operate the toolbar, use the “Ctrl+F1” key. If an element is selected, move it using the arrow keys; rotate using the “,” key and “.” key; and resize using the arrow keys with the “Ctrl” key. All of these keys can be modified with the “Shift” key to increase increment.
The design title holds the name of your design. To edit the design title, press Enter. To stop editing the design title, press Escape.
The side panel is where you can apply templates or add elements. To skip to the canvas, press “Ctrl+F2”.
Home
Use left and right arrow keys to select pages. Use Home and End to jump to the first or last page.
